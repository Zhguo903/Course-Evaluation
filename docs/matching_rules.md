# 找课匹配规则

默认展示范围内的全部官方目录课程，不先筛掉课表未检索到的课程。

1. 校区、Level、Department、分类和开课状态之间取 AND；同一筛选项的多个选择取 OR。未选择任何值表示全部。
2. 分类必须使用所属校区体系的完整标签；课程命中任一所选类别即可。
   学科筛选匹配 `subject_areas` 的任一官方分组；未映射课程使用明确标注的前缀分组，避免遗漏同时列在多个学科中的课程。
3. 搜索按空白分词，各词均需出现在课程代码、名称、学科或修读要求中。使用字面匹配，不执行正则表达式。
4. 精确课程代码优先，其次课程名称关键词命中数，最后按课程代码稳定排序。
5. 选择学期时使用该学期独立状态。全年课程同时属于秋季与冬季。
6. 匹配理由逐项列出实际满足的筛选条件。它不是质量分、学生评分或个人修读资格判断。

默认开课标注汇总当前快照覆盖的全部已发布学期。有未取消记录即为已发布开课；只有取消记录则为已取消；完整相关覆盖均不存在记录才为未找到；缺失覆盖为尚未核实。

没有可信学生反馈数据时，不计算课程难度、工作量、GPA 友好度或“水课”排名。用户仍可依据官方分类与完整要求比较课程。

v3.1 的“仅看有已导入评价”要求个人评价或已匹配历史报告至少一条；仅有外部入口不满足该条件。“仅看有课程专属资料”要求当前代码精确关联的资料至少一条，通用或未关联历史链接不计入。两项均为内容可用性筛选，不改变课程质量排序。
